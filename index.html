About

I am a Ph.D. student in the School of Computing at KAIST, advised by Prof. Jaehyuk Huh at the Computer Architecture and Systems Lab (CASYS). My research focuses on memory systems, particularly CXL-based tiered memory and secure memory architecture. I am also working on processing-near-memory (PNM) to accelerate LLM inference.

Research Interests

  • CXL-based Tiered Memory Systems
  • Processing-Near-Memory (PNM) for LLM
  • Hardware-based Memory Security
  • LLM Agent Training
